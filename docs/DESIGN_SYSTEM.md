## Motion language (all JS-driven via `window.__setT(t)`, t∈[0..1])
- Entrances: `opacity 0→1` + `translateY(18-22px)→0`, staggered per element (`start = i*0.13-0.16`, `len ≈ 0.3`)
- Numbers: count up `Math.round(ease(t*1.2) * TARGET).toLocaleString()`
- Streams/chips: items appear progressively `floor(ease(t*1.15)*N)+1`, glow via `psGlow` keyframes
- Endings: a final line fades in at `t > 0.78-0.85` (the punchline beat)
- Easing: linear on t is fine — CSS `transition: .45s ease` on the elements smooths each step
- Never animate more than ~8 elements per scene; every beat ≤0.45s apart
